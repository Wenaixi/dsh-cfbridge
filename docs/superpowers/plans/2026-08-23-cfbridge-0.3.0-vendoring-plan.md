# cfbridge 多形态与 0.3.0 全量 Vendoring 实施计划

> 面向 Agent 执行者：必需子技能：dsh-plugin-dev（Host/Preset 形态约束）+ superpower-subagent-driven-development 或 superpower-executing-plans 逐项执行。

**目标：**(1) 讲透 cfbridge 在 DSH 中的三种形态（Bundle / Agent Preset / 动态 Cordis Plugin）及选型；(2) 在已发布 0.2.0 轻量路由（997788e+d13b389）之上增量升级到 0.3.0 全量 Vendoring——把 cloudflare/skills 的 13 个 SKILL.md 原样拷入本包，使安装后 DSH 可见 14 个 skill。

**架构：**薄桥不动：cfbridge 主 skill 仍暴露 docs/search/execute 三工具；13 个 vendored skill 各配一个 src/<name>-skill.js 薄包装（复用 cfbridge-skill.js 的 ctx.skills.register 范式，resourceBase 指回 skills/<name>/），cordis.patch.yml 由 1 行扩至 14 行；包体积 +400KB，索引仅 1.7-2.5k tok，全文按需单篇加载。

**技术栈：**DSH Bundle (dsh.bundle.patch + dsh-mcp-client + dsh-skill 运行时注册), Markdown SKILL.md, Node >=22

**规格：**docs/superpowers/specs/2026-08-23-cfbridge-router-design.md + 本计划增量设计

## 全局约束
- 0.2.0 路由已发布不得回滚；0.3.0 在其上增量 vendoring，保证可回退
- 不在 cordis.patch.yml 声明 persona / agent-instructions 等 host 已有层
- Token 仍仅来自 DSH_HOME/.env 的 CLOUDFLARE_API_TOKEN，禁止写入仓库
- 13 官方 SKILL.md 原样拷入，保留 front-matter，追加 vendored 来源注释
- 版本语义：0.2.0 -> 0.3.0（feat: vendoring），CHANGELOG 追加，打 v0.3.0 tag，本地不 push

## Part A — 三种 DSH 形态
### 形态 1：DSH Bundle（主推，Host 组合）
- 路径：包根 cordis.patch.yml + package.json dsh.bundle.patch；dsh plugin --profile web add @wenaixi/cfbridge 装到 dsh.profile.bundles，重启后所有会话全局可见。
- 产物：1 个 MCP 行（mcp-cloudflare）+ N 个 skill 行（0.2.0 是 1 行，0.3.0 是 14 行）。
- 约束：不重复声明 host 已有层；failOnStartupError 保持 false；Authorization 用 !!js 模板。
### 形态 2：Agent Preset（$DSH_HOME/.agent-presets/<id>/agent.cordis.yml + preset.yml）按需
- 实现：目录 $DSH_HOME/.agent-presets/<id>/ 下放 agent.cordis.yml + preset.yml；启动会话时显式选 preset 才挂载。
- 与 Bundle 区别：Bundle=跨会话全局；Preset=按会话可选。同一能力不能同时以两种形态注册 mcp__cloudflare__*。
- 0.3.0 不强制提供实物 Preset，文档说明即可；如需另起分支 copy() 出 preset。
### 形态 3：动态 Cordis Plugin（cordis_define / cordis_run，临时探针）仅验证
- 实现：JS code.host/code.client 通过 Cordis runtime 动态注册，生命周期随卸载消失。
- 适用：临时探针/演示，不适合持久 skill。
### Skill 加载真相
- 索引阶段：仅 name/description/whenToUse 注入上下文，约 120-180 tok/skill；14 个合计 1.7-2.5k tok。
- 全文阶段：模型判定需要时才按需加载单个 SKILL.md 全文（如 wrangler 约 4.5k tok），不会一次性加载 38k tok。
